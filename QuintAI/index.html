QuintAI

A revolutionary multi-agent, multi-model question-answering system that leverages cutting-edge AI technologies to provide intelligent, accurate, and comprehensive responses through orchestrated collaboration.

Explore the Future

Core Features

Multi-Agent Architecture

Four specialized AI agents working in parallel, each leveraging different LLMs and capabilities to provide diverse perspectives on your questions.

Intelligent Judging

A sophisticated judge LLM that evaluates all agent responses and selects the most accurate, relevant, and comprehensive answer.

Retrieval-Augmented Generation

One agent specializes in answering questions based on local PDF documents using advanced vector search and embedding techniques.

Advanced Tool Integration

Wikipedia integration for real-time information retrieval, ensuring up-to-date and accurate responses to current events and topics.

Extensible Framework

Built with LangChain and LangGraph for easy integration of new agents, models, and tools to expand system capabilities.

Secure & Reliable

Robust error handling, API key management, and persistent vector storage for consistent and secure operation.

Quick Setup Guide

1

Clone Repository

Get the latest version of QuintAI

git clone https://github.com/V1629/QuintAI
cd QuintAI
2

Install Dependencies

Set up Python virtual environment and install packages

python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
3

Download Ollama Models

Install required local AI models

ollama pull llama3.2
ollama pull nomic-embed-text
4

Configure API Keys

Set up your environment variables

# Create .env file with:
groq_api_key=YOUR_KEY
groq1_api_key=YOUR_KEY
gemini_api_key=YOUR_KEY
5

Run the System

Start QuintAI and ask questions

python orchestrator.py
